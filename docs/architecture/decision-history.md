# 9. Decision History

There is no separate ADR (Architecture Decision Record) directory in this project. Significant design decisions and their reasoning are documented inline, next to the code they affect, in this file, `docs/schema/`, and `docs/api/`. The record of the migration itself — why the domains were cut over together, how the data moved, what was found after — is `docs/migration/`. If a past choice looks strange, the "why" is almost always written down close to the "what" rather than in a separate log.
