# Overview

VibeCraft is a Spring Boot backend application. Currently at initial-scaffold stage — application code has not yet been written; the v1 data model below is the design/planning target.

Based on the v1 data model, the intended domain is an AI-assisted project-building platform: users create projects, collaborate on them (ownership/membership with roles), build via AI chat sessions, store project files (backed by MinIO), get live pod-based previews, and are metered/billed through plans, subscriptions, and usage logs.
