# Overview

VibeCraft is an AI-assisted project-building platform: users describe an idea, answer a short AI-tailored interview about it, and get a project created and named from that brief; from there they collaborate on it with role-based permissions, build via AI chat sessions, store project files (backed by MinIO), get live pod-based previews, and are metered/billed through plans, subscriptions, and daily usage quotas.
